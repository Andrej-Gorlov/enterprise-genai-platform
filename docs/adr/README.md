# Architecture Decision Records (Записи о принятых архитектурных решениях)

ADR фиксируют значимые архитектурные решения проекта.

## Status

Каждый ADR может находиться в одном из состояний:

- Proposed (Предложенный)
- Accepted (Принял)
- Rejected (Отклоненный)
- Deprecated (Устарело)
- Superseded (Заменено)

После принятия ADR не переписывается так,
как будто предыдущего решения никогда не существовало.

Если архитектурное решение изменяется,
создаётся новый ADR, который supersede предыдущий.
